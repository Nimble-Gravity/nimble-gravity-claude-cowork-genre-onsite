Gen Re Cowork Workshop — Your Workshop Folder

This folder holds every document used across the three days of the workshop. Keep it on your Desktop, and keep its name exactly as it is: cowork-workshop. Every instruction in the lesson pages, and every prompt you will be asked to paste, points at that exact path.

WHAT IS IN HERE

- README.docx — this file.
- claude.md — the folder instructions Cowork reads whenever it opens this folder. Day 1 explains what it does, and by the end of Day 1 you will have replaced it with your own.
- about-me/ — where Day 1 writes your personalization files. It starts with a single template file so you can see the shape before you fill it in.
- demo/ — the document used for the Day 1 demonstration. One file.
- day-2/ — the three source documents for the Day 2 status-report exercise.

Every document in here ships twice: a .docx you open in Word, and a .txt containing the same words. Work from the .docx. The .txt is there so the file is still readable if Word is unavailable, and so facilitators can edit the source. The one exception is claude.md, which is a plain text file on purpose — that file is part of what Day 1 teaches.

THE THREE DAYS

- Day 1 — Foundations and personal value. Uses demo/ and about-me/. You watch a document get summarized by a Cowork that knows nothing about you, then teach it who you are and watch the same ask again.
- Day 2 — Skills and everyday workflows. Uses day-2/. You write a weekly status report from three source documents by hand, then turn the repeatable part of it into a skill.
- Day 3 — Use cases and governance. Uses your own work, plus whatever you have written into about-me/ over the previous two days.

DO NOT RENAME THIS FOLDER

Not the folder, and not the files inside it. Renaming is the single most common reason an instruction stops working mid-exercise, and it costs you and a facilitator ten minutes each to find. If you want a copy to experiment on, copy the whole folder somewhere else and leave this one alone.

The same goes for where it lives. It belongs at Desktop\cowork-workshop. Not in Downloads, not inside another folder of the same name, and not on OneDrive — sync can hold a file open while Cowork is trying to write to it, and debugging that is not how we want to spend the morning.

IF SOMETHING IS MISSING

Open the folder in File Explorer and compare it against the list above. If a folder or a file is not there, the extract did not finish — delete the folder, unzip the download again, and check a second time.

If it still does not match, say so before the session rather than during it.
