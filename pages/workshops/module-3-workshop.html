Backup demo — facilitators

If the live build stalls, the facilitator runs the prepared demo skill instead of debugging on the projector. The prepared skill, the files it runs on, and the point at which to make the call are all in the facilitator guide. Deciding to switch is not a failure of the session; a fifteen-minute silent debug in front of the room is.

The live build runs on the files that come with the selected use case, staged by the facilitator in a folder everyone can reach. Bring the same cowork-workshop folder you've used all week — the lab folder drops inside it.
