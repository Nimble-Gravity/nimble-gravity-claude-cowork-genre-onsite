The Workshop Folder

Cowork only sees the folders you hand it. For the next three days that's one folder on your Desktop, cowork-workshop, holding every file we use. Set it up once here and every instruction for the rest of the program points at the same place.

Foundations & Personal Value · ~15 min
01 — Set up the workshop folder

Download it, unzip it, hand it over

Five steps, about five minutes. Do them now, in order — everything on Days 1, 2 and 3 assumes the folder is exactly where these steps put it.

1
Download workshop-folder.zip from the pre-work page.
It holds every document we work on across the three days, so nobody has to hunt for a file mid-exercise or work from a different version than the person next to them.
The zip lands in your Downloads folder.
2
Right-click the zip, choose Extract All, and extract it to your Desktop.
Cowork works on real files on disk. It can't read inside a zip, and files left in Downloads get lost among everything else you downloaded this month.
3
Make the path read exactly Desktop\cowork-workshop.
Windows likes to nest the contents inside a second folder of the same name, or append a number — rename or move things until it doesn't. Every instruction for the next three days uses this exact path, so a mismatch here becomes ten minutes of confusion later.
Explorer's address bar reads …\Desktop\cowork-workshop, and you can see the files immediately inside it — not another folder of the same name.
4
In Cowork, open the folder picker and select Desktop\cowork-workshop.
This is the whole data-access model: Cowork reads and writes inside the folders you hand it and nowhere else. Handing it one folder is how you keep a capable agent scoped to the job.
Ask "Which folder are you working in?" — it answers with a path ending in cowork-workshop, not "I don't have access to a folder".
5
Ask Cowork to list everything in the folder. Compare what comes back against README.docx.
This is the first and smallest version of the habit the whole program is built on — you check the output against the source rather than taking it on trust. It also proves the grant actually worked before you depend on it.
You see about-me/, demo/, day-2/, README.docx and a claude.md. Anything missing means the extract didn't finish — flag a facilitator.
📁
It could be any folder — but this week it's this one

There's nothing special about the Desktop. Back at your desk you'll point Cowork at a project folder, and it can be a OneDrive or SharePoint folder too. For these three days everyone works in this one local folder, because sync can lag or throw up a conflict copy while Cowork has files open — and debugging somebody's OneDrive is not how we're spending the morning.

🖥️
Two windows, side by side

On a 14-inch laptop, put Claude on the left half of the screen and File Explorer on the right: Win + ← and Win + →. You never need more than those two windows, and seeing files change in Explorer while Cowork works is half of what makes it click.

02 — What the grant actually gives Cowork

Scoped to the folder, but not a closed box

Handing over a folder is a real permission, and it's worth being precise about what it does and doesn't mean — particularly the part most people get wrong.

Scope

Only the folders you grant

Cowork can't reach files outside the folders you've added — not the drive above, not your Documents, not the network share. If it needs another folder, you grant that one too, explicitly. And whatever the mode, it asks before it permanently deletes anything.

Access is per folder, for the work at hand.
Isolation

Code runs in a separate VM

Reading and writing happens directly in the folder you granted. When a task needs to run something — recalculating a spreadsheet, building a chart — that runs in an isolated virtual machine rather than loose on your system.

Capable, but boxed in by design.
☁️
"It runs locally" is half the story — say the other half out loud

The files stay on your machine. The reading does not: whatever Cowork opens in a granted folder is sent to Anthropic's service to be processed, the same as text you paste into chat. That's why the scope of the grant matters — and why the rule about keeping confidential cedent material out of this pilot isn't ceremony. Day 3 covers what that means for the enterprise, in writing.
